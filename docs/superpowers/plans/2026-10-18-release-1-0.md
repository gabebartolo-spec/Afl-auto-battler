# Aussie Rules Dynasties 1.0 Release Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

> **Authority.** This plan is context, not authorisation (CLAUDE.md). Nothing in it starts until the director
> assigns it. Phase 0 ends with his rulings; every later phase is scheduled from them. Where this plan disagrees
> with `docs/DESIGN_BIBLE.md`, the bible wins.

**Goal:** Ship 1.0: a career you can play for twenty seasons on Android, PC and web, where your coaching visibly
changes the match, every screen is readable at a glance, and no save from 0.1.x is lost.

**Architecture:** Release in four patches on the existing itch channel: 0.2.0 "Pre-season" (in flight), 0.3.0
"Match day" (the bible's current focus: players react to your calls), 0.4.0 "The long career" (onboarding,
long-save integrity, content), then 1.0 (release candidate, freeze, his full-season playtest). Unfinished work
stays behind `Features` switches (`scripts/core/Features.gd`) until its patch; at 1.0 every switch is either on
by default or deleted. The release-engineering tasks (Phase 1) are specified here to the test; each feature
phase gets its own detailed plan, written when the director assigns it, because each is a separate subsystem.

**Tech Stack:** Godot 4.7 / GDScript; suites via `tools/run_tests.sh` (each counts its own test functions);
GitHub Actions (`tests.yml` sharded, `audit.yml`, `web.yml`, `capture.yml`); butler to itch.

**Spec:** `docs/DESIGN_BIBLE.md` (vision, pillars, feature test, balance rule) and
`docs/roadmap/open-requirements.md` (rows cited as R#). Playtest chapters 26 and 27 (PR #748) hold his rulings.

## Global Constraints

- Mobile first, portrait first: 360, 390 and 412 px portrait; no hover-only information; natural Android Back.
- PC is not a big phone: landscape layouts use the screen (director's 300% 4K canvas); no empty columns.
- Dark theme only. Light theme parked (director 2026-10-13): no light captures, tests or work.
- Readability pillar: every name in text in club ink (`UiKit.club_ink`, never `club_name_colour`); sections
  distinct by club colour and bold; nothing the coach decides on in uniform grey.
- Decision gates show each option's upside, downside, size and odds, as percentages in football words, and never which option is better (bible §4, director 2026-10-18). No UI vomit, no "best choice" labels or suggested line-ups.
- Natural AFL language; sentence case; every check and button one concrete question in the copy's words.
- What the coach says or decides can affect the sim; how the club looks or sounds never does (weather excepted).
- Balance is settled only by numbers close to real AFL AND his playtest. No agent declares it done.
- Saves: existing saves load; new keys default safely; no persisted key renamed without migration.
- Captures: never Collingwood (use Fremantle, Melbourne, Bulldogs, St Kilda); merged on current main; art
  passes `art-qa-critic` and a fresh critic before he sees it.
- Spend: Tripo within the 15,000-credit approval (ch. 26 s10); any other spend (Play Store fee, signing service,
  font licence, domain) needs his written yes in the decision log first.
- Every patch note is checked line by line against what the build does (ch. 26 s8).

## Review Focus

1. **A 0.1.x save opened in 1.0.** `CareerSave._blob_at` returns `{}` when `version != VERSION`, so a version
   bump silently drops the career to the main menu. Expect: it migrates, or the player is told and the file is
   kept. Pinned by Task 1.1.
2. **A web player reloads the tab mid-season.** `user://` lives in IndexedDB; a reload, a private window or
   cleared site data must not leave a half-written career. Expect: the last good save loads or New Career is
   offered with a plain message. Pinned by Task 1.3.
3. **Season 15 and beyond.** Save size, generated-player degradation, duplicate history, cap dead ends and
   frame time drift only show in long careers. Expect: season 20 plays like season 2. Pinned by Task 1.4.
4. **"Sim the week" across a stop.** Simming must still halt for decisions that are the coach's (finals cards,
   draft, contracts with deadlines, pre-season blocks). Expect: no mandatory decision skipped, none decided for
   him. Pinned by Task 1.5.
5. **A switch left half-on.** A feature merged behind a switch can leak state into saves made with it off.
   Expect: with every switch at its 1.0 default, a career started on 0.2.0 plays on. Pinned by Task 1.2.
