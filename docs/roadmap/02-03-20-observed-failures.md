#### Core flow and decisions
- **PC fullscreen/maximised UI unreadable (`P0`, 2026-10-06).** Near-4K Windows: New career is a tiny central form in empty space; text, options and Back too small. Requirement: repair global desktop scaling and responsive fit under **STYLE-07**; verify all principal screens, not this form alone. Usability defect, not decorative polish.
- **Match simulation can freeze/stall.** Open.
- **Residual far-away receiver / loose-ball wait.** The visualisation waits for a distant predetermined player while nearer players stand off, after the earlier match-flow repair. Unresolved core-flow defect. Trace the cause (MatchSim choosing a distant next actor, MatchDirector/Motion over-honouring the event actor, or presentation not handing the loose ball to a local contestant); smallest fix that keeps MatchSim authority and balance; never change football outcomes for smoother animation. Acceptance: no visible stall for a far player when a nearby eligible player could contest; any unavoidable long run has a football reason visible in the simulation state; regression/replay coverage of the observed pattern.
- **Synergies opaque.** The user cannot reason about why a combination should work. Open.
- **Choices insufficiently informed.** Pre-match and in-match options are clicked in hope, not decided from understandable evidence. Open.
- **Results give too little feedback** to connect a decision to what followed. Open.

#### Audits (team identity, balance, performance)
- **How-we-play data maturity / season-learning audit.** After the three-match unlock, `How we win / How we get beaten` can feel fixed for the season. Code is not frozen (`_note_form_and_team()` adds every match; `_style_found()` recomputes on read), so treat it as a confidence problem unless testing proves otherwise. Audit stickiness of the first three-game traits, early-outlier dominance, and whether new evidence can promote/demote/reorder. Prefer sample-size-aware thresholds or shrinkage over UI; if copy is needed, an "early read" treatment, no confidence bars or numbers. Acceptance: profile recomputed from all season data after each match; three-game identities provisional; a material change in performance changes the surfaced traits; genuine traits harden as evidence grows; late-season read demonstrably more reliable than the first. Deterministic progression tests at 3, 6, 12 and 20+ games. Owner none (register 28).
- **How-we-win / get-beaten materiality audit.** The section surfaces trivial deviations as identities (+2 conceded from turnovers, -1 scored); cause: `_style_found()` needs only a 7% relative gap and an absolute difference rounding to 1, so low-baseline stats and correlated symptoms stack. Requirement: metric-specific minimum effect sizes from league distributions and match impact; suppress trivial differences; collapse correlated lines into one football diagnosis; prefer leading indicators the player can act on (territory, stoppages, turnovers, pressure, retention, aerial); phrase as a tendency or omit when causation is unsupported; each weakness has a football lever, no best-button recommendation. Acceptance: a +1/-2 points-a-game line never headlines; at most 2-3 material, non-duplicate traits; each understandable and actionable; seeded season tests show surfaced traits match real differences in outcomes or play. Owner none (register 28).
